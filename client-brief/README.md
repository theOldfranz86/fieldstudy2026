# Brief del mandante

Questa cartella conterrà le informazioni specifiche presentate nella seconda settimana.

File previsti:

- `CLIENT_BRIEF.md`: problema manageriale, decisione da supportare, target, territorio, vincoli e aspettative;
- `CLIENT_DATA_INVENTORY.md`: dati già disponibili e condizioni di accesso;
- `OPEN_QUESTIONS.md`: punti da chiarire con il mandante;
- eventuali documenti o riferimenti autorizzati.

Fino all’inserimento del brief, i materiali didattici devono restare astratti e non devono inventare informazioni sul caso.
