# Materiali didattici

Mantieni qui soltanto materiali derivati dalle specifiche del corso. Ogni file deve indicare settimana, learning outcome, attività prevista, fonte e versione.

Usa il formato `WNN-descrizione-breve`, per esempio `W04-qualitative-sampling.md` o `W10-analysis-workshop.md`. Conserva fonti esterne e materiali originali separati secondo `readings/SOURCE_REGISTRY.yaml`.

Per ogni settimana completa prima il pacchetto `SESSION_PLAN.md`, `SLIDE_BRIEF.md`, `COACHING_GUIDE.md`, `DELIVERABLE.md` e `QUALITY_CHECKLIST.md`. Genera un PPTX soltanto dopo le revisioni pedagogica, metodologica e visiva richieste.
