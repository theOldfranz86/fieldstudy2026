# Field Study 2026

Repository didattico per il corso **Field Study 2 – Application**.

Il repository separa:

- l’architettura stabile del corso;
- il brief del mandante, introdotto nella seconda settimana;
- i materiali settimanali e le slide;
- le consegne, i checkpoint e la valutazione;
- le istruzioni e le skill Codex per generare e verificare i materiali.

## Avvio con Codex

1. Leggere `AGENTS.md`.
2. Consultare `COURSE_CONTEXT.md` e i file YAML come fonti di verità.
3. Generare i materiali di una sola settimana alla volta.
4. Salvare i materiali in `teaching-materials/slides/week-XX/`.
5. Approvare `SLIDE_BRIEF.md` prima di produrre il PowerPoint.
6. Eseguire il controllo qualità prima di chiudere la settimana.

## Stato

Questa prima versione contiene l’impalcatura del corso. Il brief specifico del mandante sarà aggiunto in `client-brief/` dopo la presentazione della seconda settimana.
