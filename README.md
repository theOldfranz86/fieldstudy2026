# Field Study 2 – Application

Repository operativo per progettare, erogare e valutare il corso HES-SO Valais-Wallis – Haute école de gestion 2026–2027.

## Stato

L'architettura locale è la fonte autorevole ed è pronta per la produzione controllata dei materiali settimanali. Sono confermati:

- 12 sessioni da 180 minuti in francese;
- briefing metodologico, workshop, lavoro di progetto e coaching;
- disegno sequenziale qualitativo → questionario quantitativo → Sphinx → analisi integrata;
- almeno un'intervista per studente e almeno 300 risposte quantitative complete utilizzabili;
- orale di gruppo 50%, esame individuale 50% e processo progettuale formativo 0%;
- nessun rapporto scritto valutato.

Il problema manageriale di Maison Maye resta `TBD` fino al brief del 22.09.2026. Non deve essere anticipato o inventato nei materiali W01.

## Fonti di verità

| Livello | Funzione | Fonte principale |
| --- | --- | --- |
| Governance | Identità, metodo, calendario, milestone e valutazione | YAML alla radice |
| Pedagogia | Constructive alignment e ciclo esperienziale | `curriculum/PEDAGOGICAL_FRAMEWORK.md` |
| Curriculum | Progressione e learning outcomes | `curriculum/` |
| Erogazione | Letture, slide, handout, template ed esempi | `teaching-materials/` |
| Monitoraggio | Checkpoint, avanzamento e scadenze | `project-management/` |
| Valutazione | Rubriche, esame individuale e feedback | `evaluation/` |
| Automazione | Skill locali per produrre e verificare il corso | `.agents/skills/` |

## Pipeline settimanale

Per ogni settimana produrre e approvare, in quest'ordine:

1. `SESSION_PLAN.md`;
2. `SLIDE_BRIEF.md`;
3. `COACHING_GUIDE.md`;
4. `DELIVERABLE.md`;
5. `QUALITY_CHECKLIST.md`;
6. solo successivamente il file PPTX.

La prossima fase prevista è la progettazione di W01; questo aggiornamento non genera slide né PPTX.
